# Лаба 5 Работа с базой данных PostgreSQL

## Задание

Разработайте Django-приложение, которое использует PostgreSQL в качестве базы данных. Настройте модели и миграции для создания таблиц и управления данными.

### Описание задания

- [ ] Добавьте новый функционал к предыдущему проекту, где данных хранились в файлах формата JSON/XML. Теперь пользователь может выбрать, куда сохранять введенные данные с формы: либо в файл, либо в базу данных.
- [ ] При сохранении данных в БД необходимо реализовать проверку на дубликаты, в случае, если такая запись уже присутствует, то не добавлять в БД, и выводить соответствующее сообщение.
- [ ] Реализовать возможность выбора источника вывода данных на страницу: либо с файлов JSON/XML, либо с базы данных.
- [ ] Для данных, которые хранятся в БД, реализовать AJAX поиск по полям текстового формата.
- [ ] Для данных, которые хранятся в БД, реализовать возможность редактирования и удаления существующих записей. При редактировании данных проверять корректность вводимых значений.

## Настрока Django без Docker

### Настрока Питона

Сохраняем список всех установлинных в питон пакетов

```sh
pip freeze > requirements.txt
```

Устанавливаем в питон список пакетов

```sh
pip install -r requirements.txt
```

### Как создать новый серер

```sh
django-admin startproject server 
```

### Как создать модуль

```sh
python manage.py startapp module_name
```

### Кака запустить джанго

```sh
cd server

python manage.py runserver
```

### Запуск Докера композа

```sh
docker compose up
```

### Зайти в оболочку контейнера

```sh
docker exec -it container_name sh
# docker exec -it django-db sh
```

или

```sh
docker compose exec service_name sh
# docker compose exec db sh
```
